# brazil-2026-election-forensics

Анализ результатов президентских выборов в Бразилии 2026 года (1-й тур 4 октября,
2-й тур 25 октября) по участкам методом Шпилькина.

Данные: [Portal de Dados Abertos do TSE, Resultados 2026](https://dadosabertos.tse.jus.br/dataset/resultados-2026)
— `votacao_secao_2026_BR` (голоса кандидатов по участкам) и
`detalhe_votacao_secao_2026` (явка по участкам). TSE перезаписывает файлы по тем же
адресам, после 2-го тура в них оба тура.

## Запуск

```r
renv::restore()
source("R/01_download.R")  # ~480 МБ архивов в data/raw/ (перекачивает, если файл на сервере изменился)
source("R/02_prepare.R")   # data/processed/secoes_t1.rds, secoes_t2.rds
for (LANG in c("ru", "en", "pt")) {             # язык подписей, тексты в R/textos.R
  for (TURNO in 1:2) source("R/03_shpilkin.R")  # output/<язык>/t1/, output/<язык>/t2/
  source("R/04_comparacao.R")                   # output/<язык>/comparacao/
}
```

Без `LANG` скрипты строят графики на русском. Монте-Карло-тест (6) занимает
несколько минут на тур и повторяется для каждого языка.

## Что в `output/<язык>/t<тур>/`

| Файл | Содержание |
|---|---|
| `01_shpilkin_votos_por_turnout.png` | голоса кандидатов в зависимости от явки на участке |
| `02_turnout_vs_share.png` | плотность "явка x доля кандидата" |
| `03_shpilkin_por_regiao.png` | (1) по пяти регионам |
| `04_turnout_por_uf.png` | распределение явки по штатам |
| `05_histogramas_finas.png` | гистограммы с шагом 0.1 п.п. — пики на круглых процентах |
| `06_teste_inteiros.csv` | Монте-Карло-тест на избыток целых процентов |
| `07_resumo_uf.csv` | сводка по штатам: явка, доли, корреляция явки и доли |

Во 2-м туре доля Flávio = 1 − доля Lula, поэтому в (5) и (6) показана только доля Lula,
а третья линия в (1) и (3) — пустые и недействительные бюллетени.

## Что в `output/<язык>/comparacao/`

| Файл | Содержание |
|---|---|
| `01_delta_turnout_por_regiao.png` | изменение явки между турами на тех же участках |
| `02_delta_turnout_vs_delta_votos.png` | прирост явки x прирост голосов кандидата (вброс дал бы наклон ≈ 1) |
| `03_resumo_uf.csv` | по штатам: явка в обоих турах, доля участков с падением явки > 10 п.п., наклоны |

Из анализа исключены неоткрывшиеся участки, зарубежные участки (`SG_UF == "ZZ"`)
и участки с числом избирателей меньше 50 (`MIN_APTOS`).
